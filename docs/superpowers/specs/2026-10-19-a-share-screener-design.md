# A 股全市场筛选工具：第一版设计

日期：2026-10-19。状态：供用户审阅，尚未实现。

## 目标与已确认需求

用于个人在本机按放量、突破、涨跌幅等条件筛选股票，界面以方便操作为优先。

- 覆盖沪市主板、深市主板、创业板、科创板、北交所，各市场可单独勾选。
- 默认排除 ST／*ST、停牌及上市不足 60 个交易日的股票，三个排除项均可取消。
- 支持手动刷新。用户补充：若接口每日有限额，可以完全不用自动刷新。

据此采用保守默认：手动刷新，自动刷新关闭；不为满足一分钟频率消耗未知额度。后续仅在确认接口限制、用户开启开关后每 60 秒刷新。

## 技术与使用方式

采用 Python + Streamlit，在 Windows 本地启动，浏览器操作。交付启动入口、依赖清单和中文使用说明。安装依赖属于首次设置，日常启动不重复安装。

相比独立定制网页，该方案适合先完成筛选逻辑；相比桌面 GUI，能减少界面及打包维护工作。当前目录为空，尚无可沿用的代码，当前命令环境未找到 Git，因此设计文件保存于本地，不声称已提交版本库。

## 页面与操作

1. 顶部：立即刷新行情、自动刷新开关（默认关）、数据获取时间、数据源行情时间（若提供）、数据状态及覆盖统计。
2. 左侧：市场勾选、三个默认排除项，以及可独立启用的涨跌幅区间、量比下限、成交额下限、突破周期条件。
3. 主区域：筛选结果表，显示代码、名称、市场、最新价、涨跌幅、量比、成交额、突破状态；允许排序、加入自选和导出 CSV。
4. 详情区：选择股票后查看缓存中的日 K 线和成交量。若缺历史数据，显示单独的“获取／更新历史数据”按钮及待获取数量，不因点击行自动消耗接口额度。

数值筛选初始关闭，用户启用后设置阈值，避免把示例参数当作选股策略。所有启用条件按 AND 组合，边界值包含在涨跌幅、量比和成交额范围内。导出结果附带数据状态和获取时间，代码按文本保留前导零。

## 数据接入与额度

第一候选为 AKShare 的公开行情接入，正式采用前必须在本机检查五个市场的实际覆盖、字段、可访问性和上游限制。其文档列有沪深京快照、北交所快照及日线接口；文档存在不代表当前网络可访问，也不保证无额度或无频率限制。

接口适配器分离证券目录、行情快照、交易日历和历史行情，方便在公开源不可用时替换。没有明确的可用额度信息时显示“额度未知”，不能宣称无限调用；不自动购买或接入付费服务。

- 启动时先加载本地缓存；无缓存时展示空状态和初始化数据按钮，不自动访问行情源。
- 明确区分“刷新行情”和“补齐基础／历史数据”。首次初始化及历史补齐可能涉及多次请求，操作前列出待处理股票数和请求数估计。
- 一次刷新按钮不等于一次 HTTP 请求：适配器记录可观测的分页、重试与逐股请求；无法测量 SDK 内部请求数时标记未知，不把逻辑调用数当作供应商扣费数。
- 已知限额才提供额度保护；额度未知时仅手动操作、限制并发，不声称能严格防止超额。配额、鉴权、限流响应立即停止任务，不循环重试。
- 请求进行中禁用重复操作。筛选、排序、导出和查看缓存不触发网络请求。
- 手动刷新绕过行情缓存，确实发起一次刷新任务；失败保留旧快照并标示失败，不能更新旧数据的时间为本次时间。

## 筛选口径与完整性

证券主数据保存代码、交易所、板块、名称、上市日期、交易状态及数据来源。市场归属优先使用可靠主数据，不仅依赖旧代码前缀。每个市场分别显示目录股票数、快照覆盖数和缺失数；主数据不完整时不能宣称完成全市场扫描。

上市天数根据上市日期和市场交易日历计算，不用自然日或有成交的 K 线条数代替。停牌不能单凭零成交量判断。无法确认板块、上市日期、ST 或交易状态时，在相关排除条件启用的情况下记为“无法判定”，单列计数，不混入确定匹配结果。

放量条件采用数据源量比；缺失量比时，在启用该条件后标记无法判定，不填零或拿盘中累计成交量与历史全天成交量直接比较。

突破条件为最新有效价严格大于此前 N 个市场交易日内的日线最高价，N 可选 20 或 60，明确排除当前交易日。第一版标示“盘中突破”；收盘确认只在取得已完成交易日的最终收盘数据后计算，不用本机时钟推断数据已经完整。

突破使用同一价格基准。适配器必须验证历史复权价与当前价可比，并记录复权基准日；无法确认或遇到未处理的除权事件时禁用该股票的突破判断，不能直接混合旧前复权历史与当前未复权价。历史不足、日期缺口或行情时间不可靠时显示原因。

先用快照条件缩小候选，再从本地历史缓存计算突破。候选缺少历史数据时列为待补齐，展示“已评估／候选总数”和未评估名单，用户可主动获取缺失历史；不静默截取前若干股票冒充全市场结果。关闭突破条件后不要求无关历史数据。

## 本地结构与刷新

- 界面层：Streamlit 页面、筛选表单、结果表、详情和状态提示。
- 数据适配层：外部请求、字段与单位标准化、来源能力及异常分类。
- 存储层：本地 SQLite 保存证券目录、日线、行情快照、自选与偏好；按数据集记录时间、来源和完整性。
- 筛选层：无网络的纯计算，输入标准化数据和条件，输出匹配、未匹配、无法判定三类结果。
- 刷新协调层：请求互斥、任务进度、停止、额度检查与原子替换快照，避免新旧批次混杂。

自动刷新仅在用户开启且页面会话活跃时运行；休市时暂停自动行情请求，手动按钮仍可用。交易日历失效时停用自动刷新并解释原因。后台任务尚未结束时跳过下一次周期，不堆积请求。关闭页面不承诺后台监控。

## 验收

- 五个市场均能被独立选择，缺失市场或缺失股票有明确提示。
- 默认手动模式启动后不发行情请求；改筛选条件、排序和导出不联网；刷新按钮可发起任务且不能重复并发。
- 排除规则覆盖 ST／*ST、停牌、上市 59／60 个交易日边界和元数据缺失。
- 涨跌幅、量比和成交额的边界、单位和缺失值有测试。
- 突破测试覆盖相等不算突破、排除今日、历史不足、日期缺口和复权基准不一致。
- 历史补齐失败、部分行情缺失和接口限额错误不伪装成完整成功；失败仍可查看旧数据。
- 本地测试使用固定样例；另做有限的真实数据连通检查，明确区分测试样例与真实行情，不以模拟界面替代接入验证。
- 在 Windows 验证启动入口、浏览器操作、CSV 中文和代码前导零。

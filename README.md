# A 股筛选工作台

## 今日概览与自选跟踪

打开程序先显示“今日概览”：最近复盘的目标日期、状态、处理进度和更新时间一目了然；点击“开始今日复盘”使用最近一次的市场、来源和排除设置（首次使用则取默认设置），点击“继续上次复盘”继续未完成记录。打开概览或切换页面不会自动联网，按钮旁会显示将采用的设置；需要修改时进入“每日复盘”。“自选跟踪”读取本地自选与最近复盘，展示是否入选、较上次变化、距 SNAKEA 的百分比和已有历史 K 线；缺少复盘或行情时明确显示未覆盖，不自动下载。

自选跟踪页可手动点击“刷新全部自选股行情”：腾讯批量读取自选股报价，单独保存在 `watch_quotes` 中，不覆盖全市场行情及其获取时间；默认同时逐只更新前复权日K与图表指标，可取消勾选只刷新报价。每只股票的报价时间和指标日线日期分别显示。单股日K失败保留旧缓存并继续其他股票，遇接口限流停止后续历史请求；页面显示成功数量与失败原因。打开页面或切换自选股票不会请求接口。

每日复盘可比较上一个目标交易日的相同市场及排除设置记录，分为新入选、持续入选、今日退出、待确认。同一天的多次复盘不作为跨日比较；只有两次对同一股票都有明确且已核验的入选/未入选结果才判断进出，缺失、失败、排除或批量初筛未核验均为待确认。扫描未完成时这些数字是暂时结果。表格新增收盘价距 SNAKEA%、SNAKEA 日变化%、停损下限数值及颜色；旧记录缺少所需历史时显示数据不足。所有对比与排序均在本地进行。

个人使用的本地选股工具。Python + Streamlit，浏览器操作，默认手动刷新；支持沪市主板、深市主板、创业板、科创板、北交所。

## 便携版：换电脑直接用

1. 将 `A-share-screener-Windows-x64.zip` 复制到另一台 Windows 10/11 64 位电脑。
2. **完整解压**到可写目录，例如文档文件夹。不要直接在压缩包内启动。
3. 双击 `start.bat`，浏览器会打开本地页面。便携版带有 Python 和依赖，不需要另外安装 Python。
4. 保持启动窗口打开；使用完按 Ctrl+C 停止。若关掉浏览器，服务仍运行到启动窗口结束。

只监听 `127.0.0.1`，不自动发布到互联网。行情刷新需联网；已缓存数据和演示模式可离线使用。

便携包是 Windows x64 版本，不能直接用于 macOS、Linux 或 Windows ARM 原生环境。已在本机使用独立运行时验证；未在你的其他电脑实机测试。

首次运行没有真实行情缓存。左侧“演示模式”可体验页面，演示股票和日历均为合成数据，与真实数据库分开。

## 第一次获取真实行情

1. 展开“基础资料与数据管理”，点击“更新所选基础资料”。五个项目分别为沪市主板、科创板、深市主板和创业板、北交所、交易日历。
2. 选择腾讯行情，点击“立即刷新行情”。腾讯需要已有证券目录；也可手动选择东方财富。
3. 点击“更新停牌状态”。默认排除停牌，状态缺失时会列为无法判定。
4. 在左侧启用需要的涨跌幅、量比、成交额、突破条件。修改条件只计算缓存，不联网。
5. 使用突破条件时按需补齐历史。每股至少两次历史调用；默认列出五只待补齐候选，可自行选择批次。所有未完成候选都会保留并显示数量。

未知资料不会当作筛选通过。可以到“无法判定”查看原因。取消某项排除条件只取消这项检查，不会自动补数据。

## 数据口径

- 涨跌幅单位为百分数，成交额输入单位为亿元，导出为元；成交量为手。
- 放量使用行情源的量比，不用盘中成交量直接除以历史全天成交量。
- 突破使用此前 20 或 60 个市场交易日的最高价，排除当日；等于高点不算突破。
- 历史取前复权日线，并用相同日期的未复权收盘价校验当前基准；日期、复权基准或历史完整性不满足时不输出突破结论。
- 页面中的突破是盘中价格判断，不是“收盘确认”，也不是预测。
- 上市不足 60 天依据交易日历计数，包含上市当日。停牌状态取独立停复牌资料，零成交不会直接认定停牌。
- 腾讯提供行情时间；东方财富快照在当前适配器中未提供交易时间，因此不会用它直接判断突破。
- “获取时间”和“行情时间”分别展示。缓存可能过期，需手动刷新。
- 公开数据源没有已确认的每日额度保障，自动刷新暂不提供。按钮的一次操作可能包含分页、多只证券及 SDK 内部请求；日志中的 SDK 次数不等于额度扣费次数。
- 请求失败保留旧快照；超时终止。遇到限流停止任务，不循环重试。
- 预计复牌日期不等于实际复牌确认，存在该类记录时保守列为无法判定。已知行情日期落后于本批次日期的股票也不直接通过筛选。

## 自选、导出与迁移

选择结果表下方的股票查看 K 线，点击“加入自选”。表格标题可排序，可按代码／名称搜索。导出 CSV 带 UTF-8 BOM；证券代码使用前置单引号保护前导零，导入其他程序时可按文本移除这一保护符。

真实数据保存在 `data/market.db`，演示数据在 `data/demo.db`。自选和筛选偏好也保存在对应数据库。迁移个人使用状态时，先关闭应用，再复制**整个文件夹，包括 data 目录**。分享给其他人可提供原始便携压缩包；该压缩包不含你的缓存和自选。

## 源码开发

需要 Python 3.12。首次运行 `setup.bat` 安装依赖；日常运行 `start.bat`。开发环境下也可执行：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
.\.venv\Scripts\python.exe -m pytest -q
```

结构：

- `app.py`：界面与交互。
- `screener/core.py`：纯筛选和 CSV 导出。
- `screener/provider.py`、`worker.py`：字段标准化及有超时的外部请求。
- `screener/store.py`、`service.py`：SQLite 缓存和显式刷新任务。
- `tools/build_portable.py`：使用当前独立 CPython 和安装依赖制作便携包。
- `tools/check_live.py`、`initialize_and_check.py`：显式联网验证脚本；日常启动不会执行。

依赖版本见 `requirements-lock.txt`。便携包保留 Python 的 LICENSE 和依赖的 dist-info 授权文件。请保留这些文件。

### 2026-10-20 历史来源调整

历史日线默认切换为腾讯，在页面“历史数据来源”中可手动选择东方财富备用。该选择独立于实时行情来源；切换不发起网络请求，单股更新和批量补齐都使用所选来源。历史缓存标注来源，换源后需要点击更新才会替换现有缓存。腾讯的返回范围可能超出请求日期，程序会按目标日期过滤，并继续检查前复权与未复权价格基准。科创板成交量从股统一换算为手。

### 个股均线与走势状态

个股详情增加 MA5、MA10、MA20（前复权收盘价简单移动平均），以及最近20根日K收盘价的最小二乘拟合趋势线。计算时使用全部缓存历史，再截取60根、120根或全部显示；切换范围不改变均线口径，不发起网络请求。趋势线只拟合当前最近20根，不延伸预测未来。

“偏进攻”需同时满足 MA5 > MA10 > MA20、日K收盘价 ≥ MA5、MA20较上一根上行、20根拟合斜率为正。“偏防守”为全部反向条件；条件不一致显示“震荡观察”。至少需要21根有效收盘价；缺失数据不强行输出状态。

页面标注日线截止日期、具体判断依据。当日K线可能尚未完成，缓存也可能过期，因此状态描述的是该批日线，不代表实时走势或收盘确认。

SNAKEA 按用户确认公式绘制：`B2=SMA(SMA(SMA(C,2,1),2,1),2,1)`，`SNAKEA=HHV(MA(B2,1),13)`。C为前复权收盘价，SMA递推为本期输入与上期结果各占50%，每层以缓存首根有效值初始化。取含当根在内最近13根B2的最大值，连续满13根才显示；遇缺失值断线并重新初始化。全历史计算后截取显示，缓存起点不同可能导致与其他软件的初期数值不同。图上以青色绘制，可独立开关；走势状态仍使用均线与拟合趋势条件。

个股详情与复盘K线可切换显示停损下限：`SMA2=MA(B2,3)`；红线为 `IF(LLV(MA(B2,8),3)>=SMA2,B2,DRAWNULL)`，绿线为 `IF(B2<SMA2,B2,DRAWNULL)`。两条条件线独立计算，可能重合或同时缺失；不将颜色自动解释为交易信号。

### 全市场指标筛选

左侧新增两个默认关闭、可同时勾选的条件：

- 均线多头排列：最新缓存日K的 MA5 > MA10 > MA20，严格大于，至少20个连续市场交易日的数据。
- 日K收盘价上穿 SNAKEA：上一根收盘价 ≤ 上一根 SNAKEA，本根收盘价 > 本根 SNAKEA，至少14个连续市场交易日的数据。已经连续在线上方不算本根新上穿。

两项使用与个股图相同的前复权日线计算，勾选条件取交集，并可与涨跌幅、量比等原有条件组合。结果表及导出 CSV 增加均线多头、上穿SNAKEA和指标日线日期。日线基准日期必须与行情批次交易日一致，缺少历史、缺口、异常或过期均显示“无法判定”（存在其他明确不满足条件时仍为“未匹配”）。

开启任一历史条件后，“筛选历史准备”列出通过非历史条件的候选及待补齐股票。只在点击按钮后按所选批次下载，默认每批选中前5只；已有历史也可勾选后手动更新。普通筛选操作不联网。刷新行情不等于更新日线，盘中日K尚未收盘，信号可能变化；指标筛选描述缓存日线，不保证全市场历史已下载齐全。

### 每日复盘

顶部“股票筛选 / 每日复盘”切换入口进入复盘页，点击“开始复盘”才开始联网。复盘规则：

- 连续站上SNAKEA恰好1或2个交易日：入选，不限制SNAKEA方向。
- 连续站上超过2个交易日：仅最新SNAKEA高于前一根时入选，走平和下行排除。
- 站上指前复权日K收盘价严格大于同日SNAKEA；等于线值中断连续计数。趋势方向按相邻两根SNAKEA比较。
- 原始突破早于缓存可确认范围，但能确认持续站上超过2天且SNAKEA上行时，仍可入选，天数标注“至少”，突破日期不推测。

开始时刷新交易日历和所选市场目录，按固定复盘日期逐股读取本地历史或请求增量，默认腾讯，可选东方财富；需要联网的股票通常至少2次HTTP请求。默认同时处理2只股票，可选1～3只；不同历史请求的启动时间至少相隔1秒。首次全市场扫描可能较久。复盘按沪市主板、深市主板、创业板、科创板、北交所分别展示，不是行业或概念板块。默认排除ST及上市不足60个交易日，可在复盘设置里调整；复盘不叠加筛选页其他条件。无成交日K排除、缺失目标日K或交易日缺口标注无法判定。

后台线程扫描，页面每3秒只读取本地进度。停止在当前接口任务结束后生效，单次接口任务超时为90秒。成功结果逐股落盘；继续仅处理未处理和请求失败项，不重新请求成功项。连续3次请求失败或遇到403/429等限流提示自动暂停。两个窗口共享数据库任务占用，避免重复并行扫描。进程异常退出后占用最长180秒到期，再点击继续。

复盘历史请求支持1～10个工作线程，默认5个；工作台和每日复盘均可选择。历史任务启动间隔为0.1秒，仍受线程数上限约束。停止后调整线程数并继续可保留已有进度。并发仅提高等待网络时的吞吐量，不减少每只股票的接口调用次数，也不代表服务商允许对应速率。限流后停止派发新股票，等待已发出的请求完成并保存结果，再暂停任务。

快速复盘默认启用（仅腾讯来源）：每批最多80只股票使用腾讯批量当日行情接口取得当日开高低收，再与各股本地历史计算SNAKEA。价格接近SNAKEA、符合初筛、历史不足或价格基准不一致者继续逐股获取前复权/未复权日K核对。批量初筛未入选项不逐只核对当天前复权历史，页面单独计数并提示潜在除权偏差；需要严格逐股核验时关闭快速复盘。腾讯历史K线接口实测不支持在单个param中请求多只股票，因此首次建库仍需逐股获取。批量行情失败会暂停任务，不悄悄跳回耗时的全市场逐股扫描。

批量行情中无成交量的报价（如停牌股的开高低为0）不能组成有效日K，解析时跳过该只；它在逐股阶段走原有历史数据和无成交判断，不再使整批80只股票的校验失败。

每次开始创建独立复盘记录，同日可多次复盘。开始时重新获取交易日历、股票目录及腾讯批量行情，再逐股核对需要的历史日K。结果及命中股票完整K线保存在原data目录SQLite数据库中，不会被下一次行情刷新覆盖。符合股票按交易市场分组，表格新增行业板块列；行业来自交易所公开目录，缺失时标为“未提供”。点击分组表格中的股票行即可查看该次复盘的K线、MA5/10/20、SNAKEA及趋势线，无额外联网。扫描完成仍可能包含无法判定项，页面单独列出数量和原因。

复盘日期默认北京时间当天，非交易日取此前最近交易日；历史日期扫描采用当前目录，不能代表当时完整上市名单。若腾讯历史日K滞后一天，收盘后会在当天批量报价时间不早于15:05、前一交易日与历史末日一致、前收盘价与前复权历史收盘价一致时，使用当天收盘报价补算本次复盘；结果标注“腾讯收盘行情补足滞后的历史日K”，不会写入正式历史缓存。无法核对时仍列为无法判定。继续旧任务会重新获取目录和批量行情，并重试“目标日的日K尚未返回”的股票；其他已成功处理的快照保留。演示模式禁用真实复盘扫描。

### 本地历史数据库与增量更新

历史保存在 `data/market.db`（SQLite文件数据库），无需安装数据库服务。复盘、筛选和个股详情共用这份历史；原有历史自动作为可用缓存参与更新。迁移时复制整个data文件夹。

首次获取约220个日历日的历史；后续请求从本地最后5根日K起，到目标日为止，保留更早记录并按日期合并去重。这段重叠用于核对前复权价格，最后一根可能是盘中K线，不把其价格正常变化误当作除权。重叠的已过去日K价格发生变化或缺失时，重新请求完整历史窗口；旧版本另存档，获取失败不破坏原缓存。数据源若限制可返回历史长度，重新获取后的活动窗口可能缩短，旧复盘K线快照仍保留。

同一来源已有目标日日K，且缓存获取时间在该日北京时间15:30之后时，复盘默认直接读取本地；盘中数据仍请求更新。可勾选“重新获取已有收盘缓存”主动更新。个股详情的手动更新始终请求接口。旧日期复盘不会覆盖较新日期的历史缓存。

增量请求不等于服务商只返回一天或只扣一次额度：腾讯可能忽略日期范围返回更长区间，程序会本地过滤；前复权与未复权校验通常仍需两次HTTP请求，价格基准变化时会追加完整窗口请求。页面分别统计本地复用、增量、首次/换源和基准变化重取数量，并显示原行情获取时间。
